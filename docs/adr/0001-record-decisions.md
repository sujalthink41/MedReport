# ADR 0001 — Record architecture decisions

**Status:** accepted · **Date:** 2026-09-05

We record significant architecture decisions here, one file per decision.

Format: `NNNN-short-title.md` with Status / Date / Context / Decision / Consequences.

A decision goes in an ADR when reversing it would cost more than a day, or when a
future reader would reasonably ask "why on earth did they do it that way."
